# 변이 전수 측정

테스트가 정말 무언가를 재는지 — 소스의 판정을 하나씩 뒤집고(`if-py`: `if 조건` → `if not (조건)`)
비교 경계를 한 칸 옮겨(`boundary`: `<` ↔ `<=`) 테스트 5종이 빨개지는지 전수로 잰다.
"못 잡음" 줄은 **그 줄을 지키는 단언이 하나도 없다**는 뜻이다(동치 변이 — 바꿔도 결과가 같은 것 — 일 수도 있다).
