# 화면 글 쓰는 법

앱 화면에 나가는 모든 글(안내, 오류, 빈 화면, 분석 문장, 말풍선, 산출 방법, 이용 안내)에 적용합니다.
2026-11-14 부터는 **GitHub 에 올라가는 공개 글**에도 같은 규칙을 씁니다.

| 글 | 적용 | 지키는 장치 |
|---|---|---|
| README, CHANGELOG | 전부 고쳤습니다(2026-11-14) | `tools/check_public_text.py` (`tests/test_rules.py` 가 부릅니다) |
| 릴리스 본문 | 틀을 고쳤고, 올라간 36개도 고쳤습니다 | `tests/test_release.py` 가 `release_notes()` 로 만든 본문을 잽니다 |
| 개발 문서(`docs/`), `CLAUDE.md`, 코드 주석 | 차례로 고칩니다 | 사람이 봅니다 |
| 커밋 메시지 | 앞으로 쓰는 것부터 | 사람이 봅니다. 지난 커밋은 번호가 바뀌어 고치지 않습니다 |

커밋 메시지는 제목을 짧은 명사형으로 쓰고, 본문은 합쇼체로 씁니다. 본문에서도 줄표로 문장을 잇지 않습니다.

**기준**
- 「한글 맞춤법」과 부록 「문장 부호」(국립국어원 · 2015 개정)
- 「국어기본법」 제14조(공공기관 문서는 누구나 알기 쉬운 용어와 문장으로)와 국립국어원 쉬운 공공언어 쓰기 지침
- 쉬운 글쓰기 원칙(Plain Language): 짧은 문장, 능동형, 현재형, 한 문장에 한 가지 말
- 공식 안내문 말투: 사용자에게는 합쇼체로 정중하게, 무슨 일인지 먼저 말하고 무엇을 하면 되는지 이어서 말합니다

`tests/test_rules.py` 의 `test_ui_text_style` 이 아래 규칙 중 기계로 셀 수 있는 것을 지킵니다(표에 ✔).

## 규칙

| # | 규칙 | 검사 |
|---|---|---|
| 1 | 문장은 **"~합니다/~입니다"(합쇼체)**로 끝냅니다. "~아니다", "~한다" 같은 해라체를 섞지 않습니다 | ✔ 0 |
| 2 | **줄표(—)로 문장을 잇지 않습니다.** 문장 부호 규정에서 줄표는 제목 뒤 부제를 보일 때 씁니다. 두 말을 이으려면 문장을 끊습니다 | ✔ 파일별 상한(0 을 향해 줄입니다) |
| 3 | **가운뎃점(·)은 대등한 낱말을 늘어놓을 때만** 씁니다(예: 승·무·패). 문장 뒤에 붙여 다음 조각을 잇지 않습니다 | ✔ 문장 뒤 가운뎃점 0 |
| 4 | 괄호 덧붙임은 **한 문장에 하나**까지만 씁니다. 괄호 안에 또 괄호나 줄표를 넣지 않습니다 | 사람이 봅니다 |
| 5 | 한 문장에 한 가지 말만 합니다. 대략 40자를 넘으면 끊을 곳이 있는지 봅니다 | 사람이 봅니다 |
| 6 | 쉬운 말을 씁니다. 통계·개발 용어는 꼭 필요할 때만, 처음 나올 때 풀어 줍니다 | 사람이 봅니다 |
| 7 | 능동형으로 씁니다. 이중 피동("~되어집니다", "잊혀지다")과 어색한 말("먹혔습니다")을 쓰지 않습니다 | ✔ 금지어 0 |
| 8 | 오류·빈 화면은 **무슨 일인지 → 무엇을 하면 되는지** 순서로 씁니다. 따라 할 수 없는 안내는 쓰지 않습니다 | 사람이 봅니다 |
| 9 | 부탁은 "~해 주세요", 할 수 있는 일은 "~할 수 있습니다"로 씁니다 | 사람이 봅니다 |

짧은 상태 표시(표 칸, 칩, 단추)는 명사로 끝내도 됩니다. 예: `없음`, `모으는 중`, `다시 시도`.

## 바꾼 예

| 전 | 후 |
|---|---|
| 랭킹 수집이 여러 번 연속 실패했습니다 — {사유} · 간격을 늘려 다시 시도합니다 | 랭킹 수집이 여러 번 실패했습니다. 잠시 후 간격을 늘려 다시 시도합니다. (사유: {사유}) |
| 시세를 모으는 중입니다 · 12/200장 · 약 3일 뒤 | 시세를 모으는 중입니다(12/200장). 약 3일 뒤부터 볼 수 있습니다. |
| 경기당 1.2골 넣고 0.9골 먹혔습니다. | 경기당 평균 1.2골을 넣고 0.9골을 내줬습니다. |
| 이름과 달리 유효슛 대비 득점률이 아니다. | 이름과 달리 유효 슛 대비 득점률이 아닙니다. |
| 양끝을 끌어 구간을 좁힙니다 · 두 번 누르면 전체 | 양 끝을 끌어 구간을 좁힐 수 있습니다. 두 번 누르면 전체 구간으로 돌아갑니다. |

## 고치는 순서

1. 빈 화면·오류·상태 안내 → 대시보드·분석 문장 → 말풍선·산출 방법
2. **이용 안내(동의 화면)는 마지막에** 고칩니다. 글을 바꾸면 `config.NOTICE_VERSION` 을 올려야 하고, 모든 사용자에게 동의를 다시 받습니다. 안내 내용이 실제로 바뀔 때 함께 고칩니다.
3. 줄표를 줄였으면 `tests/test_rules.py` 의 `STYLE_DASH_MAX` 도 지금 개수로 내립니다(테스트가 알려 줍니다).
