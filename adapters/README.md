# 어댑터 — 카카오톡에 붙이기

`bot/server.py`(서버)는 전적을 조회하고 답할 텍스트를 만들 뿐, 카카오톡을
직접 만지지 않는다. 방에서 메시지를 읽어 서버로 넘기고 답장을 방에 넣는 일은
**어댑터**가 한다.

| 어댑터 | 대상 | 상태 |
|--------|------|------|
| `kakao_bot.js` | 안드로이드 봇 앱(메신저봇R) — PC 에뮬레이터·실제 폰 공용 | 있음 |
| `pc_kakao.py` | PC 카카오톡 창 자동화 | 아직 없음(다음 단계) |

카카오 공식 챗봇(오픈빌더)은 **오픈채팅방에 들어갈 수 없다.** 그래서 비공식
경로를 쓴다 — 아래 "위험" 항목을 먼저 읽을 것.

---

## kakao_bot.js — 봇 앱 어댑터

에뮬레이터와 실제 폰에서 **같은 파일**을 쓴다. 다른 건 서버 주소 한 줄뿐이다.

### 1. PC에서 서버를 켠다

```powershell
python -m bot.server
```

기본이 `0.0.0.0:8765` 라 다른 기기에서 붙을 수 있다.
`--host 127.0.0.1` 로 켜면 **에뮬레이터·폰에서 접속되지 않는다**(그 PC 안에서만).

### 2. 서버 주소를 정한다

`kakao_bot.js` 맨 위 `SERVER` 한 줄을 고친다.

| 붙이는 곳 | 주소 |
|-----------|------|
| 안드로이드 스튜디오 AVD | `http://10.0.2.2:8765` (에뮬레이터에서 호스트 PC를 가리키는 고정 주소) |
| LDPlayer·녹스·MEmu 등 | `http://10.0.2.2:8765` 를 먼저 시도하고, 안 되면 PC 내부 IP |
| 실제 폰 (같은 와이파이) | `http://<PC 내부 IP>:8765` |

PC 내부 IP는 `ipconfig` 의 IPv4 주소다(보통 `192.168.x.x`).

```powershell
ipconfig | Select-String "IPv4"
```

**주소가 맞는지 먼저 확인할 것.** 에뮬레이터나 폰의 브라우저에서
`http://<주소>:8765/health` 를 열어 `{"ok": true}` 가 보이면 통과다.
여기서 막히면 스크립트를 아무리 고쳐도 안 된다.

안 열린다면:
- 서버를 `--host 127.0.0.1` 로 켰는지
- 윈도우 방화벽이 8765 인바운드를 막는지 — 관리자 PowerShell에서:
  ```powershell
  netsh advfirewall firewall add rule name="fifa-bot" dir=in action=allow protocol=TCP localport=8765
  ```
- 폰과 PC가 같은 와이파이인지(휴대폰 데이터로는 안 된다)

### 3. 메신저봇R에 스크립트를 넣는다

1. 안드로이드 기기(에뮬 또는 폰)에 **메신저봇R**을 설치한다. 구글 플레이에는
   없고 공식 배포처에서 APK를 받아야 한다.
2. 앱에서 새 스크립트를 만들고 `kakao_bot.js` 내용을 통째로 붙여 넣는다.
3. **알림 접근 권한**을 허용한다. 이 방식은 카톡 알림을 읽고 알림의 답장창으로
   답을 넣는 구조라, 권한이 없으면 아무것도 못 한다.
4. 배터리 최적화에서 메신저봇R을 제외한다(안 하면 잠든 사이 죽는다).
5. 스크립트를 켠다(전원 버튼).

### 4. 카톡 쪽 설정

- 봇을 돌릴 계정이 **그 오픈채팅방에 들어가 있어야** 한다.
- **그 방의 알림을 켜 둬야 한다.** 알림이 오지 않으면 어댑터가 메시지를 볼 수
  없다 — 방을 조용히 해두면 봇이 먹통이 된다.

### 5. 확인

방에 `!도움` 을 친다. 명령 목록이 오면 끝이다.
이어서 `!등록 <구단주명>` 을 해두면 그 뒤로는 `!전적`, `!오늘` 처럼 짧게 칠 수 있다.

PC의 서버 콘솔에도 처리한 명령이 한 줄씩 찍힌다:

```
[bot] 피파방 / 홍길동: !전적 GB쭈우
```

## 문제 해결

| 증상 | 볼 곳 |
|------|-------|
| 아무 반응이 없다 | 방 알림이 켜져 있는지 · 메신저봇R 스크립트가 켜져 있는지 · 서버 콘솔에 줄이 찍히는지 |
| "봇 서버에 연결하지 못했습니다" | 2단계의 `/health` 확인부터 다시. 주소·방화벽 문제다 |
| 서버 콘솔엔 찍히는데 답이 없다 | 메신저봇R의 알림 접근 권한 · 답장 대상 방이 맞는지 |
| 답이 중간에 잘린다 | 카톡이 긴 메시지를 접는 것이라 정상 — 말풍선의 "전체 보기" |
| 명령을 연달아 쳤는데 하나만 답한다 | 정상. 같은 사람이 같은 명령을 다시 치면 10초 쿨다운(호출량 보호). `!등록`·`!해제`·`!도움` 은 예외 |
| 조회가 몇 초 걸린다 | 정상. 쌓인 경기가 많은 계정의 첫 조회가 그렇다(실측 3,772경기에 2.8초). 이후 120초 동안은 즉답 |

## 위험

- 비공식 방식이다. 카카오 약관상 자동화 도구 사용은 **계정 이용 제한 사유가
  될 수 있다.** 주력 계정 대신 부계정을 쓰는 것을 권한다.
- 서버에 인증이 없다. 같은 공유기의 다른 기기도 부를 수 있으니 신뢰하는
  망에서만 켜고, 공유기에서 외부로 포트를 열지 말 것.
