# 카카오톡 오픈채팅 봇 — 공용 서버

채팅방에 명령어를 치면 전적을 답해 주는 봇의 **서버 쪽**이다.
카카오 공식 챗봇(오픈빌더)은 오픈채팅방에 들어갈 수 없어서, 방에 실제로
메시지를 넣고 빼는 일은 별도의 **어댑터**가 맡는다. 서버는 어댑터가
무엇이든 상관하지 않는다 — HTTP 엔드포인트 하나만 본다.

방에 붙이는 방법은 [adapters/README.md](../adapters/README.md) 를 볼 것.
지금 있는 어댑터는 안드로이드 봇 앱용(`adapters/kakao_bot.js` — PC 에뮬레이터와
실제 폰 공용)이고, PC 카카오톡 창 자동화는 다음 단계다.

## 실행

```powershell
python -m bot.server                       # 0.0.0.0:8765
python -m bot.server --host 127.0.0.1 --port 9000
```

GUI 앱과 같은 `.env`(`NEXON_API_KEY`)·같은 DB를 쓴다. 키가 없으면 켜지지 않는다.

## 명령어

| 명령 | 하는 일 |
|------|---------|
| `!전적 <구단주명>` | 누적 요약(등급·승률·평균 득실·연승) + 최근 5경기 |
| `!최근 <구단주명> [개수]` | 최근 경기 목록 (기본 5, 최대 15) |
| `!상대 <구단주명> [상대명]` | 자주 만난 상대 8명 / 특정 상대와의 상성 |
| `!선수 <구단주명>` | 출전이 많은 선수 8명의 골·도움·평점 |
| `!랭킹 <구단주명>` | 감독모드 순위·구단가치·팀컬러 (데이터센터 스크래핑) |
| `!도움` | 명령 안내 |

구단주명을 빼면 **그 방에서 마지막으로 조회한 계정**을 쓴다.
`!` 로 시작하지 않는 메시지와 모르는 명령에는 아무 답도 하지 않는다
(같은 방에 다른 봇이 있을 수 있다).

## HTTP 계약

어댑터가 지켜야 할 전부다.

```
POST /message   {"room": "방 이름", "sender": "보낸 사람", "text": "!전적 홍길동"}
             →  {"reply": "..."}      답장할 텍스트
             →  {"reply": null}       봇이 반응하지 않을 메시지 — 그냥 무시할 것

GET  /health →  {"ok": true}
```

**타임아웃은 넉넉히(60초 이상) 잡을 것.** 처음 보는 계정이거나 쌓인 경기가
많으면 첫 응답이 몇 초 걸린다(실측: 3,772경기 누적 계정에서 2.8초).
같은 계정의 두 번째 명령부터는 캐시로 0.0~0.3초다.

## 조회 정책 — GUI와 다른 점

- **전량 백필을 하지 않는다.** GUI는 처음 보는 계정의 전 경기를 받지만(수천 건이면
  수 분), 봇은 최근 20경기만 새로 받고 나머지는 DB에 쌓인 만큼으로 답한다.
- **`accounts` 테이블을 건드리지 않는다.** GUI의 "최근 검색" 목록이 채팅방
  사람들 닉네임으로 뒤덮이면 안 된다.
- 집계는 API 응답이 아니라 DB에서 다시 읽는다 — GUI로 예전에 쌓아 둔 경기까지
  같이 잡힌다.
- 감독모드(`matchtype=52`) 전적만 본다.

## 호출량·안전

- 방별로 같은 명령은 **10초 쿨다운**, 전역 **분당 20회** 상한. 넘으면 답하지
  않거나(쿨다운) 안내한다(전역).
- 조회 결과는 120초 캐시 — 연달아 치는 명령이 API를 다시 타지 않는다.
- 호출량을 넘기면 넥슨이 `OPENAPI00007`을 준다. 사람이 읽는 한글 메시지로
  바꿔서 답한다.
- **인증이 없다.** 기본 바인딩이 `0.0.0.0`이라 같은 공유기의 다른 기기도 부를
  수 있다 — 신뢰하는 망에서만 켤 것. 외부에 포트를 열지 말 것.
- 비공식 경로로 카카오톡에 붙이는 것이므로 계정 이용 제한 위험이 있다. 부계정 권장.

## 파일

| 파일 | 역할 |
|------|------|
| `service.py` | 조회 파이프라인 — API·DB를 만지는 유일한 곳. 캐시도 여기 |
| `formatters.py` | 집계 결과 → 카톡 텍스트 (고정폭 폰트가 아니라 표 대신 줄바꿈) |
| `commands.py` | 명령어 파싱 · 쿨다운 · 에러 문구 |
| `server.py` | `ThreadingHTTPServer` — 의존성 0(stdlib) |
